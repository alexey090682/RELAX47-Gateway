Причина расхождения — каталог подключённого клиента не отражает команды
установленного сервера. В 7.14.12 gateway_status возвращает имена команд
самого сервера, чтобы проверять это без чтения исходников.

Предыдущая подготовка миграции сохраняла только закрытый SQL-снимок Store.
Она не устанавливала рабочую базу и не переключала существующие интеграции.
В 7.14.12 добавлен отдельный перенос с совместимым SQL Store-адаптером.
Точный охват, ограничения, условия запуска и отката описаны в README.md.

Обнаружено и исправлено отсутствие новых команд в проверке mcp:admin.
Проверены запрет вызовов и сокрытие инструментов для токена без admin.

Проверки: 51 offline unit/integration test, компиляция Python, bash -n,
git diff --check. Использованы настоящие временные SQLite-базы, но Supervisor
подменён. Контейнерная сборка в этой рабочей среде не выполнена.
Совместимость импорта проверена по текущему коду шести модулей HA; два экспорта
содержат скрытые секретные строки и требуют серверного preflight.

Публикация/установка Gateway не означает, что миграция уже запущена.
После обновления нужны актуальный каталог MCP, серверный preflight, окно
обслуживания и проверка живых интеграций после переноса.
