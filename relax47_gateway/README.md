# RELAX47 Local Gateway 7.14.0

Управляемый шлюз Home Assistant OS и Xiaomi AX6000 RA72.

Публичный endpoint `<public_base_url>/mcp` поддерживает независимые Streamable
HTTP-сессии ChatGPT, Claude/Claude Code и программных клиентов. Каждый клиент
проходит OAuth Authorization Code с PKCE и получает отдельный `Mcp-Session-Id`.
Чтения могут выполняться параллельно, изменяющие операции сериализуются, а
идентификаторы клиента, сессии и запроса попадают в аудит.

Подключение Claude Code:

```sh
claude mcp add --transport http relax47 https://relax47-home.duckdns.org/mcp
```

В Claude Web используется тот же URL как Custom Connector. Код активации,
OAuth-токены и учётные данные Home Assistant нельзя передавать в чат или в
аргументах командной строки.

Административный OAuth scope `mcp:admin` открывает ChatGPT, Claude и Claude Code
неинтерактивную терминальную диагностику, безопасное чтение Supervisor,
передачу и транзакционное применение файлов, backup, проверку конфигурации,
перезапуск Core и управление приложениями. Терминал запускает только
read-only команды без shell; секреты, `.storage`, `/ssl` и host internals
закрыты. Изменения выполняются существующими аудируемыми инструментами с
резервной копией и проверкой результата.

Версия предоставляет инвентаризацию Home Assistant, клиентов, DHCP, LAN-портов
и Tuya; проверяемые DHCP-изменения; резервное копирование Home Assistant;
транзакционное создание и обновление LocalTuya с безопасным DP-пробированием,
откатом одного устройства и продолжением пакетной миграции после ошибки.

Связь работает двумя способами: исходящий Secure MCP Tunnel или прямой публичный
HTTPS MCP с OAuth по адресу `/mcp`. Для объекта RELAX47 используется прямой
вариант через `relax47-home.duckdns.org`, поскольку старый туннель возвращал
региональный `403`.

`localtuya_sync_keys` собирает local keys через уже авторизованную официальную
интеграцию Tuya и сохраняет их в `/share/RELAX47_TUYA_KEYS.json` с правами
`0600`. MCP-инструменты не принимают и не возвращают ключи, токены или пароли;
официальная облачная Tuya не изменяется и не отключается.

Версия 7.12.0 также добавляет автономное обслуживание: проверяемую передачу
файлов частями, загрузку и частичное восстановление backup через Supervisor,
самообновление шлюза, управление дополнениями и транзакционное изменение
конфигурации Home Assistant. Перед изменением создаётся backup, новая
конфигурация проверяется через Supervisor, а неуспешная запись откатывается.
Прямое чтение `.storage`, `secrets.yaml`, базы данных и credentials запрещено.
