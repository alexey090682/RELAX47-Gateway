# RELAX47 Gateway 7.14.17

Добавлена безопасная загрузка занятых дат RealtyCalendar через два iCalendar-экспорта.

- Ссылки задаются в защищённых полях конфигурации дополнения и не выводятся в диагностику.
- Оба объявления считаются одним объектом RELAX47; одинаковые интервалы объединяются.
- В Home Assistant передаются только UID и даты. Имена гостей, телефоны и описания из iCalendar не копируются.
- Каждый новый снимок заменяет предыдущий для своего источника, поэтому открытые повторно даты удаляются из занятости.
- Webhook продолжает отдельно обрабатывать новые заявки Avito/ЦИАН.

После установки вставьте обе ссылки «Экспорт» в конфигурацию дополнения и перезапустите шлюз.
