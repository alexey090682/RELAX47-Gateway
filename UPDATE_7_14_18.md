# RELAX47 Gateway 7.14.18

Подключает публичный личный кабинет Relax47 к серверу.

- API: `https://relax47-home.duckdns.org/mcp/site-account`
- SQL: `/data/RELAX47_SITE.db`
- Пароли: PBKDF2-HMAC-SHA256 с индивидуальной солью
- Сессии: отзываемые непрозрачные токены, в SQL хранятся только SHA-256
- Изоляция: учётные записи сайта отделены от администраторов Home Assistant и рабочей `relax47.db`
- Разрешённые источники: `https://relax-47.ru` и Firebase-адрес сайта

Поддерживаются регистрация, вход, выход, проверка сессии, сохранение и получение предварительных расчётов.
